# Concesionario multimarca con showroom 3D interactivo

Aplicación web para un concesionario multimarca que combina un catálogo de vehículos nuevos, km 0 y de ocasión con un showroom 3D interactivo, donde se pueden examinar y personalizar determinados modelos antes de contactar con el concesionario.

> Proyecto final del ciclo DAW (2.º curso, 2026-27). Encargo simulado: no usa datos de empresas ni personas reales.

**Estado:** en desarrollo (fase de análisis y documentación).

## Motivación

Las webs de compraventa de vehículos de ocasión revisadas se apoyan sobre todo en fotos fijas y fichas planas. Este proyecto permite ver el coche desde distintas perspectivas y cambiarle el color en el navegador, integrado con un catálogo con búsqueda y filtros.

## Funcionalidades previstas

Imprescindibles:

- Catálogo con búsqueda, filtros (marca, modelo, precio, año, kilometraje, combustible y estado), ordenación y fichas de vehículo
- Backend y base de datos que alimentan el catálogo y las fichas
- Showroom 3D: transiciones de cámara, vistas predefinidas, vista libre y vista rotativa automática
- Personalización visual del modelo (color de carrocería)
- Formulario de solicitud de información

Deseables:

- Página principal con vehículos destacados
- Favoritos y comparación de vehículos
- Puntos de información sobre partes del vehículo (equipamiento y estado real)

## Tecnologías

HTML5, CSS3 y JavaScript · Three.js · Java 21 con Spring Boot · SQL (MySQL o PostgreSQL, por decidir) · Modelos 3D en glTF/GLB · Despliegue web (por confirmar)
